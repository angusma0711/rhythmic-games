# rhythmic games · 三組節奏題庫

直接用瀏覽器開啟 index.html。全頁離線可用，沒有CDN、網絡API或登入。原P2_Rhythm_Game與P2_Rhythm_Revision沒有修改。

## 課堂操作

1. 先選年級，再在「節奏題庫」選一組，每組含六個八拍組合，先讓學生看完整兩行四格的譜。
2. 選內建伴奏，按開始：四拍預備 → 八拍跟着拍 → 八拍自己拍。
3. 第一遍有伴奏、示範鼓聲及逐拍亮格；第二遍保留伴奏及逐拍亮格，不播放節奏示範鼓聲。兩遍不中斷，不插入預備拍。
4. 不顯示下一題預告。兩遍完成後，新譜直接切換到主畫面並開始下一題，背景音樂及拍奏不中斷，不插入讀譜休息。只有最初開始時有四拍預備。第六題完成後停止，不循環回第一題。途中可按停止；重新開始一律由四拍預備起步。手動下一題仍只換題，由教師按開始。

每格一拍；ti-ti的兩次起音都在同一格內。休止時伴奏繼續，學生安靜一拍。沒有口訣、移動提示、自動分數或掌握紀錄。教師觀察拍子是否穩定、八分是否均分及休止是否保留時間。題庫是原創元素練習，不是出版社指定節奏或已確認考題。

## 音樂設定

內建音樂以Web Audio合成輕鼓、低音、C–Am–F–G和弦，預設80 BPM，也可選60或100。音樂節奏不隨題目變化，16拍的伴奏可重複播放。伴奏及示範音量分開設定。

自選音樂：載入本機MP3、M4A或WAV（以瀏覽器實際解碼為準）；設定40–160 BPM及第一拍的秒數，可填0及小數。按「對拍試聽」從設定位置播放八拍音樂＋拍子聲。若不吻合，調整數值後再試。

正式練習需要設定位置之後足夠完成剩餘題目的音樂，長度不足會提示。從第1題開始共需96拍（80 BPM為72秒）；從第6題開始只需16拍。四拍預備後連續播放選定片段，不變速、不自動找拍點；只適用速度穩定的音樂。換檔清除BPM及第一拍設定；重新開頁須重新載入。檔案只解碼到記憶體，不上傳、不儲存。

回合中鎖定題目和音樂設定。停止、切題、換來源、頁面隱藏或音訊中斷均取消排程；重新開始由四拍預備起步。

## 驗證及限制

- verify.cjs：六題八拍、時值及休止、80 BPM的750/375ms、4+8+8階段、第二遍無答案聲、伴奏連續、自選片段長度及起點、八拍試聽、解碼錯誤、換檔清除設定、非同步取消及背景停止。
- 瀏覽器實際驗證：開始與結束、WAV載入解碼、長度不足提示、對拍試聽、停止及內建／自選來源切換。
- 桌面約805×763及1024×768橫向主畫面為四欄兩行、無垂直捲動。
- 真實iPad觸控、Safari解碼／音訊啟用、音響或藍牙實際聲畫延遲尚未驗證；音色及音量仍須課室試聽。MP3／M4A未用真實檔案逐一測試。

測試命令：node verify.cjs。遊戲本身不需要Node。

年級選擇版：進入時先選P2／P3／P5，不自動記住上次年級。P2保留既有六題；P3另有六題；P5有六題（見下文）。第一遍及第二遍都逐拍亮格，第二遍只有背景伴奏，不播放節奏答案。GitHub專案名稱使用rhythmic-games。


## P3 考試範圍與記譜

依使用者提供的考試範圍相片：二分音符、附點四分音符、八分音符及四分音符。按使用者要求，附點四分必須緊接八分，共兩拍，不能單獨出題。每題八拍，每行四拍；二分音符與附點組合各佔兩個欄位，不把一個音符當作一拍。二分音符只起音一次，維持兩拍；附點組合兩次起音在0及1.5拍。兩拍組合不跨行。二分以空心符頭繪製，單獨八分音符保留符尾。格內不顯示拍數說明。

P3六題（每項代表一個節奏單位）：
1. 二分／二分／二分／二分
2. 四分／四分／二分／四分／四分／二分
3. 附點組合／二分／附點組合／二分
4. 四分／四分／附點組合／二分／四分／四分
5. 二分／附點組合／四分／四分／附點組合
6. 附點組合／附點組合／二分／附點組合

以上是按考試元素編寫的練習句，不是正式試題。P3不加入相片未列明的休止、成對八分或其他音值。來源相片不包含於GitHub上傳檔案。

更換年級會停止音訊及重置題號，但保留已設定的音樂來源、BPM及本次載入音樂。兩遍仍有彩色亮格；第二遍不播示範鼓聲。測試覆蓋年級首頁、P2保留、P3兩拍分組及起音、P5題庫和切年級取消音訊。


## P5 考試範圍與記譜

依2026–27五年級上學期考試範圍「節奏」部分，只用以下五種節奏型，每種佔一拍：八分接兩個十六分（起音0、½、¾拍）、成對八分、附點八分接十六分（起音0、¾拍）、四個十六分、四分音符。每題八拍，每行四拍，不加入範圍外的休止或音值。

P5六題（每格一拍，循序加入新節奏型）：
1. 四分／成對八分交替
2. 八分＋兩十六分／四分交替
3. 附點八分＋十六分／四分交替
4. 四個十六分／四分交替
5. 八分＋兩十六分／成對八分／附點八分＋十六分／四分 ×2
6. 八分＋兩十六分／四個十六分／附點八分＋十六分／成對八分／四分／附點八分＋十六分／四個十六分／四分

以上是按考試元素編寫的練習句，不是正式試題。來源相片不包含於GitHub上傳檔案。

## 課室操作改進

- 鍵盤／簡報筆：空白鍵、Enter、「.」或B開始／停止；→或PgDn下一題，←或PgUp上一題；R再練一次；F投影模式。輸入框內按鍵不受影響；回合中不能換題。
- 聲畫延遲：教師設定內有0–400 ms滑桿及「拍手校正」。校正播放12下拍子聲（90 BPM），聽到就按空白鍵或按鈕，取第3–12下的中位數。亮格及階段顯示按此延遲推後，聲音排程不變。數值只存於此裝置瀏覽器（localStorage）；私密瀏覽可能不保存。
- 投影模式：全螢幕、隱藏設定及頁腳、放大狀態文字及譜、加粗格線及高對比亮格。按Esc或「離開投影」返回。
- 階段顯示：預備拍及兩遍拍奏使用淡藍色，配合明確階段文字；完成灰色。
- 尚未驗證：真實藍牙／投影喇叭的校正結果、實體簡報筆按鍵、iPad Safari全螢幕（iPhone不支援網頁全螢幕）。

## 年級伴奏與示範聲

- 伴奏按年級改變，和弦仍為C–Am–F–G：P2保持原有八分鈸及鼓；P3較柔和，四分鈸、兩拍一個低音、三角波長和弦，配合二分及附點組合；P5用十六分鈸（八分位置較重）、第三拍後半的補鼓及八分低音，配合十六分節奏。和弦用兩個略為走音的振盪器，使投影喇叭聲音較飽滿。
- 預備拍改為木魚聲（第一拍較高），與伴奏及示範鼓聲分開。沒有使用語音數拍：瀏覽器語音合成的時間無法準確對齊拍子，也視乎裝置是否有中文語音。
- 示範聲按音符長度：一拍或以下只有鼓聲；1½拍及二拍的音符在鼓聲後加持續長音，維持整個音值，讓學生聽到「拍一下，等兩拍」。
- 自選音樂不加伴奏，只有預備拍及示範聲。

## 設計及版面

- 年級顏色：P2青綠、P3橙、P5紫；年級色只用於首頁卡片頂線、圖示及年級標籤；操作及進度統一使用藍色。首頁有標誌及各年級代表節奏圖示。
- 每格左上角顯示拍號（每行1–4；兩拍格顯示「1–2」或「3–4」）。
- 譜下方進度條分八段，第一遍及第二遍各由零開始。
- 教師設定分「音樂」及「課室」兩組；寬度640px以上以右側抽屜開啟，不壓縮譜面。
- 「顯示節奏唸法」（預設關閉，只存於此裝置）：ta、ti-ti、ta-a、ta-i ti、ti-tiri、tim-ri、tiri-tiri；休止顯示「（休）」。各校唸法或有不同，教師可自行決定是否顯示。
- 快捷鍵說明預設隱藏，按「? 快捷鍵」或?鍵顯示。手機版縮短標題列，避免按鈕換行。

## 學生介面（2026-10 改版）

- 「清爽藍」視覺：冷白背景、深藍文字、白色譜卡、淡藍亮格。使用細邊框與輕陰影，移除跳動放大及完成彩紙，讓注意力留在讀譜。
- 學生畫面只保留：返回、年級、題號圓點（1–6，可直接點選）、狀態（預備拍大數字、跟着拍 · 第一遍、自己拍 · 第二遍、完成）、譜、進度條及開始／停止／再來／下一題。
- 教師設定（題目選單、音樂來源、速度、音量、唸法、聲畫延遲、快捷鍵說明）收在右上⚙抽屜；⛶為投影模式。
- 首頁採「聲波工作室」：藍色聲波標誌、靜態聲波主圖、「聽見音樂，拍出節奏」及三張年級卡片。拍奏畫面只加小標誌，保留原有譜面面積；所有圖像內嵌，無外部依賴。

## 拍奏提示

保留「輔助模式 · 跟音光點」開關，兩遍按實際音符起音移動，長音停留、休止隱藏；兩遍也保留逐拍亮格。不顯示下一題預告，不插入換題休息。

## 記譜繪製

所有音符由同一組度量繪製（以16單位為一個間距）：符頭大小及傾斜、符幹粗細及長度、符槓厚度及間距、附點大小一致。符幹接在符頭右緣，符槓兩端剛好對齊外側符幹；二分音符以鏤空符頭繪製（不用白色填色，亮格時不會出現白斑）；附點與符幹保持距離；附點八分＋十六分的短符槓向左；四個十六分加寬間距。

自動接題測試：P2／P3／P5全部六題順序、不顯示下一題預告、換題無休息、僅最初四拍預備、伴奏不中斷、跟音光點兩遍保留、單一自選音樂Buffer連續播放96拍、長度檢查、停止取消及第六題結束。

## 三組節奏題庫

P2／P3／P5各有三組，每組六個不同的八拍組合（每級共18個）。第1組「基礎節奏」保留原有六題；第2組「律動練習」及第3組「節奏挑戰」為新增固定組合，仍只使用各年級既有考試元素。主畫面「節奏題庫」選整組，上方1–6選該組內的組合；教師設定亦可選組合。從目前組合連續播放至第6個，每個先示範一遍、再自行拍一遍。只在最初四拍預備，不插入換題休息、不自動跳到另一題庫。

內建伴奏按組別切換：第1組「課室拍子」沿用C–Am–F–G；第2組「晴空律動」為原創G–D–Em–C伴奏與柔和正弦短旋律；第3組「星光節拍」為原創Dm–B♭–F–C伴奏與三角波短旋律。低音、和弦及短旋律在16拍循環中維持固定節拍，不模仿答案節奏。三個年級保留各自鼓組密度。60／80／100 BPM及音量設定沿用，選自選音樂時不疊加內建伴奏。全部內嵌合成，無額外音檔或網絡依賴。

切換題庫會停止音訊、回到組合1；回合中鎖定題庫選擇。跟音光點保留，不顯示下一題預告。新增測試涵蓋9個年級／題庫配搭、每組六個獨特八拍組合、P3分組邊界、所有題庫的自動接續、切題庫取消音訊及兩首新伴奏的音樂事件。
