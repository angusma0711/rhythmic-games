# rhythmic games

直接用瀏覽器開啟 index.html。全頁離線可用，沒有CDN、網絡API或登入。原P2_Rhythm_Game與P2_Rhythm_Revision沒有修改。

## 課堂操作

1. 先選年級，再選固定八拍練習之一，先讓學生看完整兩行四格的譜。
2. 選內建伴奏，按開始：四拍預備 → 八拍跟着拍 → 八拍自己拍。
3. 第一遍有伴奏、示範鼓聲及逐拍亮格；第二遍保留伴奏及逐拍亮格，不播放節奏示範鼓聲。兩遍不中斷，不插入預備拍。
4. 完成後按再練一次，或下一題（只換題，教師再按開始）。

每個基礎欄位一拍；P3二分與附點四分組合佔兩欄。ti-ti的兩次起音都在同一格內。休止時伴奏繼續，學生安靜一拍。沒有口訣、移動提示、自動分數或掌握紀錄。教師觀察拍子是否穩定、八分是否均分及休止是否保留時間。題庫是原創元素練習，不是出版社指定節奏或已確認考題。

## 音樂設定

內建音樂以Web Audio合成輕鼓、低音、C–Am–F–G和弦，預設80 BPM，也可選60或100。音樂節奏不隨題目變化，16拍的伴奏可重複播放。伴奏及示範音量分開設定。

自選音樂：載入本機MP3、M4A或WAV（以瀏覽器實際解碼為準）；設定40–160 BPM及第一拍的秒數，可填0及小數。按「對拍試聽」從設定位置播放八拍音樂＋拍子聲。若不吻合，調整數值後再試。

正式練習需要設定位置之後至少16拍音樂，長度不足會提示。四拍預備後播放選定片段16拍，不變速、不自動找拍點；只適用速度穩定的音樂。換檔清除BPM及第一拍設定；重新開頁須重新載入。檔案只解碼到記憶體，不上傳、不儲存。

回合中鎖定題目和音樂設定。停止、切題、換來源、頁面隱藏或音訊中斷均取消排程；重新開始由四拍預備起步。

## 驗證及限制

- verify.cjs：六題八拍、時值及休止、80 BPM的750/375ms、4+8+8階段、第二遍無答案聲、伴奏連續、自選片段長度及起點、八拍試聽、解碼錯誤、換檔清除設定、非同步取消及背景停止。
- 瀏覽器實際驗證：開始與結束、WAV載入解碼、長度不足提示、對拍試聽、停止及內建／自選來源切換。
- 桌面約805×763及1024×768橫向主畫面為四欄兩行、無垂直捲動。
- 真實iPad觸控、Safari解碼／音訊啟用、音響或藍牙實際聲畫延遲尚未驗證；音色及音量仍須課室試聽。MP3／M4A未用真實檔案逐一測試。

測試命令：node verify.cjs。遊戲本身不需要Node。

年級選擇版：進入時先選P2／P3／P5，不自動記住上次年級。P2保留既有六題；P3另有六題；P5按使用者提供的範圍另設六題。第一遍及第二遍都逐拍亮格，第二遍只有背景伴奏，不播放節奏答案。GitHub專案名稱使用rhythmic-games。


## P3 考試範圍與記譜

依使用者提供的考試範圍相片：二分音符、附點四分音符、八分音符及四分音符。按使用者要求，附點四分必須緊接八分，共兩拍，不能單獨出題。每題八拍，每行四拍；二分音符與附點組合各佔兩個欄位，不把一個音符當作一拍。二分音符只起音一次，維持兩拍；附點組合兩次起音在0及1.5拍。兩拍組合不跨行。二分以空心符頭繪製，單獨八分音符保留符尾。

P3六題（每項代表一個節奏單位）：
1. 二分／二分／二分／二分
2. 四分／四分／二分／四分／四分／二分
3. 附點組合／二分／附點組合／二分
4. 四分／四分／附點組合／二分／四分／四分
5. 二分／附點組合／四分／四分／附點組合
6. 附點組合／附點組合／二分／附點組合

以上是按考試元素編寫的練習句，不是正式試題。P3不加入相片未列明的休止、成對八分或其他音值。P5現已按另一張使用者提供的考試範圍另建題庫，見下節。來源相片不包含於GitHub上傳檔案。

更換年級會停止音訊及重置題號，但保留已設定的音樂來源、BPM及本次載入音樂。兩遍仍有彩色亮格；第二遍不播示範鼓聲。測試覆蓋年級首頁、P2保留、P3兩拍分組及起音、P5節奏型時值和切年級取消音訊。


## P5 考試節奏型

依使用者提供的P5範圍相片，節奏型為：八分＋兩個十六分、成對八分、附點八分＋十六分、四個十六分，以及四分音符。五種各佔一拍，不加入相片未列出的休止、二分、附點四分或其他組合。相片不隨專案上傳。

以四分為一拍，各型起音及時值：

| 型 | 相對起點 | 時值 |
|---|---|---|
| 四分 | 0 | 1 |
| 成對八分 | 0、0.5 | 0.5、0.5 |
| 八分＋兩個十六分 | 0、0.5、0.75 | 0.5、0.25、0.25 |
| 附點八分＋十六分 | 0、0.75 | 0.75、0.25 |
| 四個十六分 | 0、0.25、0.5、0.75 | 各0.25 |

六題由成對八分開始，依次加入八分＋兩十六分、附點八分＋十六分、四十六分，最後兩題混合運用。每題仍是八拍、兩行各四拍。十六分使用雙連桿；八分＋兩十六分只在後兩音加第二連桿；附點八分＋十六分有附點及末音短第二連桿。第一遍播放每次起音，兩遍均每拍亮格一次，第二遍沒有答案聲。

測試新增：P5每題八拍、全部五種節奏型的起點與時值、示範只在第一遍、第二遍亮格及年級切換取消。這些是按範圍編寫的原創練習，不是正式考試節奏句。
